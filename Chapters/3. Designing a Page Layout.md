### Fixed, Fluid, and Elastic Layouts
- **fixed** layout is a design that sets heights and widths to fixed measurements, usually in pixels. This is useful when you have full control over the end user's device e.g. kiosks
- **fluid** layout uses relative measures such as a % of the screen width
- **elastic** layouts use relative measures based on font size
The web is moving towards **responsive design** which means that websites have different layouts depending on the device being used to view the site
